# 瓷砖排版施工图编辑器

一个本地运行的瓷砖排版工具，用于快速制作铺贴方案、调整瓷砖边界、合并/分割瓷砖区域，并导出带尺寸标注的施工图 PNG 或 PDF。

项目适合用于瓷砖铺贴方案沟通、施工前排版确认、门窗/障碍扣减、局部尺寸调整和用量估算。

## 功能特性

- 支持设置铺贴区域名称、宽度、高度。
- 支持设置瓷砖宽高、缝宽和铺法。
- 支持正铺、旋转铺贴、错缝/工字铺等常用排版方式。
- 支持设置起铺点和 X/Y 偏移。
- 支持添加门窗、柱体、设备等矩形障碍，并自动扣减可铺贴面积。
- 支持单砖选中、多选、合并多块瓷砖。
- 支持选中单砖后横向分割、竖向分割，分割后的子块可继续选中和继续分割。
- 支持拖动瓷砖边界，并在调整时自动吸附到瓷砖边、障碍边、区域中心或 50mm 网格。
- 支持通过输入单块瓷砖宽高进行精确尺寸调整。
- 支持全局瓷砖颜色、单砖颜色、全局图片、单砖图片填充。
- 支持添加文字标注，文字可拖动和编辑。
- 支持 Undo / Redo。
- 支持应用内多排版 Tab，新建排版不会覆盖原方案。
- 支持刷新页面后恢复上次排版内容。
- 支持导出透明背景 PNG。
- 支持导出 CAD 风格 PDF。
- 导出的 PNG/PDF 会保留瓷砖颜色或图片填充，并显示瓷砖尺寸标注。

## 使用说明

### 1. 设置铺贴区域

在左侧「铺贴区域」中填写区域名称、宽度和高度。单位默认为毫米。

### 2. 设置瓷砖规格

在「瓷砖规格」中填写砖宽、砖高、缝宽，并选择铺法。

### 3. 调整起铺点

通过九宫格起铺点和 X/Y 偏移控制起铺位置。修改这些参数后会重新生成自动排版。

### 4. 添加障碍

点击「添加障碍」可添加门窗、管井、设备等矩形扣减区域。障碍区域会参与面积扣减和排版裁切。

### 5. 调整瓷砖边界

画布中的瓷砖边界可以拖动调整。拖动时会自动吸附到常见参考位置，也可以在右侧选中区域中输入精确宽高。

### 6. 合并瓷砖

按住 Shift、Command 或 Ctrl 选择多块相邻瓷砖后，点击「合并」可把多块瓷砖合并成一个区域，方便进行整体调整。

### 7. 分割瓷砖

选中单块瓷砖或合并后的瓷砖后，可以点击：

- 「横向分割」：按水平中线分成上下两块。
- 「竖向分割」：按垂直中线分成左右两块。

分割后的子块会作为真实瓷砖区域显示尺寸，并可继续选中和分割。

### 8. 设置颜色或图片

可以设置全局瓷砖颜色或图片，也可以选中某一块瓷砖后单独设置颜色或图片。

上传的图片只保存在当前浏览器本地，不会上传到服务器。

### 9. 添加文字标注

点击「添加文字」后，可在排版图中添加文字说明。文字支持拖动和编辑。

### 10. 多排版 Tab

点击「新建排版」会创建一个新的应用内 Tab。旧排版会保留在原 Tab 中，不会被覆盖。

## 导出

顶部工具栏支持两种导出方式：

- 「导出透明 PNG」：导出透明背景的施工图图片。
- 「导出 PDF」：导出更接近 CAD 效果的施工图 PDF。

导出内容包含：

- 铺贴区域外形。
- 瓷砖边界。
- 每块瓷砖尺寸。
- 瓷砖颜色或图片填充。
- 门窗/障碍标注。
- 整体宽高尺寸标注。
- 用量统计信息。
- 文字标注。

## 数据保存与隐私

本项目是纯前端本地工具。

- 排版数据保存在浏览器 `localStorage` 中。
- 上传的瓷砖图片会以本地数据形式保存在当前浏览器中。
- 项目不会主动上传排版数据或图片到服务器。
- 清除浏览器站点数据后，本地保存的排版也会被清除。

## 已知限制

- 当前铺贴区域以矩形为主。
- 障碍扣减以矩形为主。
- 图片资源存储在浏览器本地，过大的图片可能占用较多 localStorage 空间。
- 当前没有云端同步、账号系统或多人协作。
- 当前没有内置项目文件导入/导出格式，主要依赖浏览器本地保存和 PNG/PDF 导出。
